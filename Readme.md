# Sistema de Gestión y Control de Ciclos de Cosechas

## Tecnologías utilizadas para el desarrollo:
**HTML.-** Lenguaje de marcado de hipertexto para definir la estructura.
**CSS.- **Hojas de estilo en cascada para el diseño visual.
**JavaScript.- **Lenguaje de programación para dar funcionalidad.
**Excel/XLSX 
Git/GitHub**


## Librerías integradas:
**SheetJS,** Se utilizó para leer y procesar los archivos Excel (.xlsx) dentro del sistema. 

##Tipo de proyecto:
Sistema web de gestión y monitoreo de ciclos de cosechas.

## Descripción del proyecto:
Sistema web desarrollado para visualizar, controlar y gestionar automáticamente los ciclos de cosecha, calculando fechas, estados y progreso según las reglas establecidas para cada ciclo.

## Diseño responsivo:
Desktop: 1440px
Tablet: 720px
Móvil: 320px


## Proceso realizado
1. Definición de reglas de negocio
        ↓
2. Desarrollo del motor 1F
        ↓
3. Validación de fechas, estados y progreso
        ↓
4. Desarrollo de 2F, 3F y ETAPA 5
        ↓
5. Implementación de transiciones horarias
        ↓
6. Integración con Dashboard y filtros
        ↓
7. Pruebas y validaciones
        ↓
8. Limpieza y documentación del código
        ↓
9. Control de versiones con Git/GitHub
        ↓
10. Pull Request + revisión + Merge
        ↓
✅ VERSIÓN FINAL VALIDADA Y APROBADA


## Resultado final
Sistema web funcional y validado para el control automático de los ciclos 1F, 2F, 3F y ETAPA 5, con cálculo de fechas, estados, progreso, Dashboard, filtros y control de versiones.
