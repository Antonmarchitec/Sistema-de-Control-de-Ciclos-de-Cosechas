## 📌 Descripción del proyecto

Sistema web desarrollado para automatizar la gestión y seguimiento de ciclos de cosechas, transformando información almacenada en archivos Excel en una aplicación dinámica, organizada y fácil de utilizar.

El sistema permite procesar reglas de negocio personalizadas para los ciclos **1F, 2F, 3F y ETAPA 5**, calculando automáticamente fechas, estados y niveles de progreso, brindando una visualización clara mediante un dashboard interactivo.

Este proyecto representa la evolución de una solución basada en datos hacia una herramienta web completa, aplicando programación, automatización y buenas prácticas de desarrollo.



## 🚀 Principales funcionalidades

✅ Importación y procesamiento de archivos Excel mediante SheetJS.  
✅ Motor de reglas para cálculo automático de ciclos y fechas.  
✅ Gestión de estados dinámicos:
- EN_CURSO
- PROXIMA
- FINALIZADA

✅ Dashboard con indicadores y seguimiento visual.  
✅ Filtros y búsqueda de información.  
✅ Barras de progreso dinámicas.  
✅ Diseño responsive adaptable a diferentes dispositivos.  
✅ Modo claro y modo oscuro con persistencia de configuración.  
✅ Seguimiento de actividades operativas dentro de cada ciclo.  
✅ Identificación visual del ciclo activo mediante alertas y ventanas emergentes.



## 🛠️ Tecnologías utilizadas

- **HTML5** → Estructura del sistema.
- **CSS3** → Diseño visual, responsive y sistema de temas.
- **JavaScript** → Lógica, procesamiento y funcionalidades dinámicas.
- **SheetJS (XLSX)** → Lectura y procesamiento de archivos Excel.
- **Git / GitHub** → Control de versiones y gestión del desarrollo.

## 🔄 Proceso de desarrollo

1. Análisis de reglas de negocio.
2. Creación del motor inicial 1F.
3. Validación de fechas, estados y progreso.
4. Implementación de ciclos 2F, 3F y ETAPA 5.
5. Integración con archivos Excel mediante SheetJS.
6. Desarrollo de Dashboard y filtros.
7. Implementación de mejoras visuales y experiencia de usuario.
8. Incorporación de modo oscuro/claro.
9. Implementación de seguimiento de actividades.
10. Pruebas, validaciones y control de versiones con Git/GitHub.


## 📈 Evolución del proyecto

Durante el desarrollo se incorporaron nuevas mejoras para convertir el sistema en una herramienta más completa:

🌙 Sistema de temas claro/oscuro.  
📊 Mejoras en visualización y organización de información.  
✅ Nuevos controles de seguimiento operativo.  
⚡ Alertas visuales para identificar el ciclo y actividad actual.  
🎨 Optimización de interfaz y experiencia de usuario.
